# v3 零星工程审核业务流程

1. 用户上传施工方案、报价/白单和可选现场照片。
2. 后台 worker 解析为完整方案正文和配套清单上下文。
3. v3 AI 主审读取完整方案、经验教训手册和清单上下文，生成初审候选问题。
4. 本地 tools 只做证据检索：方案片段、清单片段、规范提示、未决经验台账。
5. AI 结合工具结果输出终审意见，再由 critic 删除偏题、无证据和机械照搬的问题。
6. 结果按分项工程进入收发室，人工逐条复审后导出 Word。
7. 误判和经验补充按单条意见提交审批，审批通过后才进入经验手册候选素材。

旧多 Agent、关键词路由、v2 经验卡匹配和低成本 triage/rerank 已停用。
