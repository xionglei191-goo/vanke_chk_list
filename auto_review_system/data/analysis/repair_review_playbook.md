# v3零星工程审核经验教训手册

## 审核目的
- 判断班组长编写的小方案能否指导施工、计价、验收和复核。
- 不做大而全施工组织设计审查，不输出安全文明费、品牌违约、超高降效等偏题套话。
- 历史经验只作为专家追问方式，不能机械照搬到当前方案。
- 每条结论必须回到当前方案证据；证据不足只能列为需复核/需补资料。

## 四个核心维度
- 描述完整性：材料、规格、参数、现场条件、验收指标是否闭合。
- 工艺合理性：材料系统、基层、环境、功能和耐久是否匹配。
- 分项拆分：拆除、修复、恢复、隐蔽、检测、保护、报价口径是否拆清。
- 逻辑自洽：工序、养护、交接、尺寸、数量、材料名词和验收口径是否冲突。
- 细部可施工性：边、角、缝、洞口、管根、倒角、新旧交接、遮蔽保护和相邻分项界面是否写到班组能照着做。

## 必查追问清单
- 看到面层翻新，不只查主材，还要追问基层验收、开放使用、边界收口、污染控制和成品保护。
- 看到石凳、台阶、挡墙、墙角、洞口、管根、门窗边、水沟边等细部，必须追问倒角、收边、接缝顺直、遮蔽保护和验收方法。
- 看到相邻分项交接，必须追问先后顺序、保护措施、是否会返工、是否会污染或破坏已完工程。
- 看到报价/白单中的分项，而方案正文没有对应施工做法，应列为分项拆分或方案清单一致性问题。

## 专家常用追问
- 专家在追问：班组、采购和验收能不能仅凭方案确定材料性能和安装参数？
- 专家在追问：关键节点是否写到班组能照着做，收口、搭接、防水、固定和保护有没有落地做法？
- 专家在追问：方案的先后顺序、固化养护、成品保护和相邻分项交接是否能避免返工？
- 专家在追问：这个做法为什么适合当前基层、环境、使用功能和耐久要求？有没有更匹配的材料系统？
- 专家在追问：这条意见依赖专家对项目上下文的经验判断，需要回到方案原文确认触发条件。
- 专家在追问：方案有没有把现场勘查结果写清楚，还是在不知道原状的情况下直接套做法？

## 可迁移审核原则
- 看到任何材料或设备名称，都反查规格、性能、厚度/强度、安装间距、容量功率、认证等级和验收指标。
- 凡出现水、缝、洞、边、角、交接、固定和新旧材料连接，都必须审核节点做法。
- 审核每个面层覆盖前的基层验收、相邻分项交接、固化养护时间和开放使用条件。
- 材料和工艺不是看能不能做，而是看是否适配基层、环境、功能、耐久和后续饰面系统。
- 先回到方案原文找触发证据，再决定是否按同类经验迁移。
- 遇到既有基层、旧饰面、渗漏、裂缝、划痕、管线、标高时，必须先要求现场确认结果和处理分支。

## 忽略后的典型风险
- 可能导致面层起鼓、脱层、开裂、接缝不顺或开放使用时间争议。
- 班组会按经验自由发挥，现场、验收和复核口径容易失控。
- 可能采用不适配做法，影响耐久性、观感或功能恢复。
- 可能形成结构连接隐患、原结构损伤或隐蔽验收无法追溯。
- 可能出现空鼓、返碱、污染、开裂或高低差等质量问题。
- 可能使用不合格材料或缺少消防/安全复核凭证。
- 可能造成方案动作无报价、清单项目无做法、重复计价或对下结算争议。
- 可能导致施工、计价、验收和复核之间无法闭环。

### 1. EPDM胶水比、固化时间、基层验收要求未明确 - 维度/类别：描述完整性｜地坪/EPDM/环氧｜材料系统性能参数不足 - 对齐状态：部分补齐 - 专家真实意图：专家在追问：班组、采购和验收能不能仅凭方案确定材料性能和安装参数？ - 缺口原因：已具体覆盖 基层验收；仅笼统提及 胶水配比、固化/养护时间。 - 泛化规则：看到任何材料或设备名称，都反查规格、性能、厚度/强度、安装间距、容量功率、认证等级和验收指标。

### 2. 石凳存在大倒角，需明确在倒角下方粘贴美纹纸收口 - 维度/类别：描述完整性｜装修翻新｜构造节点和细部收口不可施工 - 对齐状态：仍缺失 - 专家真实意图：专家在追问：关键节点是否写到班组能照着做，收口、搭接、防水、固定和保护有没有落地做法？ - 缺口原因：已对高可信匹配文件做全文检索，仍未覆盖 倒角收口，历史意见指向的关键控制点仍需补充。 - 泛化规则：凡出现水、缝、洞、边、角、交接、固定和新旧材料连接，都必须审核节点做法。
